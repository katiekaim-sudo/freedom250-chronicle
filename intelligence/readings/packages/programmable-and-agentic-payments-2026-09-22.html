# Programmable and Agentic Payment Stress Constitution

## Answer in one sentence

The next payment transition is not one smart contract replacing a bank: it is
a chain of separately governed authority, credential, software, message,
asset, settlement, title, accounting and remedy systems, and a payment is safe
only when evidence can be carried across all of them.

## What this package adds

The existing programmable-money and agentic-payment constitutions defined the
ideal transaction. This package stress-tests that design against actual
failures, three controlled payment specimens, state commercial law,
bankruptcy, assurance scope, stablecoin reserve economics and the live GENIUS
implementation clock.

## The controlling stress test

For every transaction, incident or proposed product, reconstruct:

Obligation → principal/capacity → delegation → mandate → admission →
credential/signing surface → checkout/instruction → execution → technical
settlement → legal/title result → delivery → accounting → correction/recovery
→ final loss.

Never collapse these questions:

- Did the code execute?
- Was the instruction technically authentic?
- Was it legally attributable and within authority?
- Did consideration, title or the promised service actually move?
- Which record controls if systems disagree?
- What was booked, reversed or impaired?
- Who could stop, correct or socialize the loss?

## Core finding

The most dangerous failures are **valid-looking joins between systems**. The
DAO and Mango show that executable code does not settle legal responsibility.
Nomad and Vyper show that audited application logic can inherit bridge or
compiler defects. DMM and Bybit show that a real employee or signer can approve
a substituted transaction through a compromised interface. USDC/SVB shows
that correct token code does not guarantee access to reserve cash. In every
case, the correction layer created a second transaction state; it did not make
the first event disappear.

## Authority and limits

This is research, not legal, accounting, audit or implementation advice. The
UCC amendments are model law and state text controls. Protocol documentation
establishes published behavior, not legal sufficiency or adoption scale.
Operator incident reports are identified as such. Bounded negative findings
mean only that the specified official-source search did not locate the object
through the cutoff.

The package does not alter the Chronicle, app, Catalog, canonical Return
Ledger, or any production payment system.
