 The legal route

 How an executive order moves through government

 The signature starts the instruction. Departments and agencies turn it into determinations, rules, lists and operating records; only those later records show what actually changed.

 1 President Issues the order under named constitutional or statutory authority. 

 → 
 2 Executive order Sets policy, commands action, or delegates a determination. Annex / Appendix — when present The object set: who, what product, which security, or which chair. It is not another agency. 

 → 
 3 Named department or agency Uses only the authority and consultation path the order gives it. 

 → 
 4 Implementation record Determination, regulation, list, HTS instruction, license, notice, or case. 

 → 
 5 Observable result A block, rejected trade, assessed duty, refund, notice, personnel action—or no proved change yet. 

 Parallel constraints: Congress supplies statutes, appropriations and oversight; courts may review or enjoin; OMB coordinates budgetary and administrative implementation. None is an automatic step in every order.

 See four monetary and legal routes 

 Sanctions President / Annex → Treasury → TFI → OFAC → bank or crypto custodian block + report 

 Securities DOD identification → President / Annex → Treasury / OFAC → market intermediaries reject + report trade 

 Customs President → Commerce / USTR → USITC → DHS / CBP → Treasury assess / collect / refund 

 Personnel President / Appendix → OPM → agency head → PD-marked position classify / notify / act 

 Keep the states separate: blocked is not seized · listed is not transacted · a tariff exception is not a payment · a position listing is not a person removed.
