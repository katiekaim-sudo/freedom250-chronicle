How to go deeper

  1. Open api/v1/index.json.
  2. Use inventory.json and activity.json for scope and recent-work questions.
  3. Choose packages in api/v1/packages.json.
  4. Open api/v1/packages/{research_id}.json.
  5. Read the Markdown report and public materials it names.
  6. Use the connected story map only when the question crosses packages.
  7. Freshly verify anything that must be current today.
