Read the Library with an AI assistant

The current Library has ten subjects. Start with a small directory, then read the exact study or record. Each record keeps its own evidence dates.

  1. Current Library directory
  2. Find a name or significant word: letter → two-letter prefix → word range → matching records. Intersect record keys for a multiword question.
  3. Browse the ten subjects or browse studies. A study index links its main/supporting readings and a paged list of saved collection documents, including transcripts.
  4. Open a record and follow its parts index. Continue through every next link until end_of_document. Original downloads and source links remain separate.

A collection association is navigation, not proof of a claim. Read local transcription warnings and object-local dates; export dates do not refresh evidence.
