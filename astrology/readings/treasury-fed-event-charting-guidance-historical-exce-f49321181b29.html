Preserved section 6

6. Astrological charting guidance

The timeline contains four different kinds of events that should not be collapsed into one charting convention:

  1. Statute or executive order: use the verified signing time and Washington, D.C.; if time is unavailable, record the chart as untimed.
  2. Regulatory order or final rule: use the Commission/Board vote time when available; publication date is a separate event from adoption.
  3. Reserve Bank operating change: use the actual first operation or production activation time at the operating Reserve Bank, not Board headquarters.
  4. Distributed payment-system launch: use the documented control/operation center only if verified; otherwise label the city a project convention.
  5. Speech or meeting: use the agenda start for the specific remarks and the physical venue.
  6. Application: distinguish the applicant's execution/signing from the regulator's receipt, docketing, publication, conditional approval, and final approval. Each can be a separate entity-status event.
  7. Future deadline: do not chart it as an occurred event. If testing a deadline prospectively, label the chosen legal effective-time convention explicitly.
