# Saved government website checks and source captures

Dated website captures, normalized text and candidate packets preserve what the source monitor actually saw. Candidate changes and suggested review routes are unreviewed source leads unless a completed research package separately adopts them. A changed listing is not a legal or operating change.

## What this collection preserves

The file-to-site reconciliation names each admitted source individually in `RESEARCH FILE ADMISSIONS.json`. Local originals stay in their established custody. Published copies have permanent document IDs, source dates, original downloads and complete section indexes where extraction is available.

## Source custody

workbench: `Government-Wide Source Monitor/README.md`

## Boundaries

This is a source collection and retrieval entrance, not a new substantive finding. Source type, draft/candidate status, capture failures and extraction limits remain attached. Research, social commentary, astrology and technical workflow files keep separate dispositions.
