What this adds to normal analysis

For every important transition, ask four separate questions:

  1. Clock: How many solar and sidereal days elapsed?
  2. Frame: Did Washington's ASC and MC rotate to a new stage or return to an old one?
  3. Cast: Which planets actually changed signs or houses?
  4. Command: Did the final dispositor or bounded root circuit change?

A near-identical wheel can carry a different story because phase and root have changed. A radically rotated wheel can carry the same root. Neither resemblance nor difference should be asserted from appearance alone.
