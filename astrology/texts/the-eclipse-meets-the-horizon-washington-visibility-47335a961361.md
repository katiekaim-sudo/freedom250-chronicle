## Washington visibility, 2025–2026

## Answer first

The missing eclipse layer is not another symbolic meaning. It is **where the
shadow physically lands and what Washington can actually witness**.

An eclipse reading currently joins several clocks that must remain distinct:

1. the exact Sun–Moon conjunction or opposition used to cast the astrology
   chart;
2. the astronomical instant of greatest eclipse;
3. the global eclipse type and shadow path;
4. the Washington-local eclipse type, magnitude or obscuration;
5. the local horizon: rise, set, altitude and observable duration.

These are not competing answers. They describe different layers of the same
event. The chart remains the Washington chart at exact syzygy. Local visibility
describes the event's physical staging there. Neither local visibility nor
global totality supplies factual, causal or predictive credit.

The eight-eclipse audit produces four very different kinds of stage:

- a fully witnessed nighttime eclipse high in the sky;
- an eclipse that appears or disappears at the horizon;
- a global eclipse whose Sun or Moon is above the Washington horizon but whose
  shadow geometry is elsewhere;
- a globally total eclipse experienced from Washington only as a small partial.

The word **eclipse** therefore cannot carry the whole visual meaning by itself.

## The new eclipse-hearing contract

Every future eclipse analysis should preserve these fields before
interpretation:

| Lane | Required question |
|---|---|
| Syzygy | When is the exact conjunction or opposition used for the chart? |
| Greatest eclipse | When is maximum shadow, and how far is it from syzygy? |
| Global geometry | Is the event total, annular, partial or penumbral, and where does the path or visibility region fall? |
| Washington type | Is the eclipse physically visible from the mundane chart location, and if so in what local form? |
| Horizon | Is the event rising, setting, below the horizon or fully carried across the sky? |
| Scale | What are the local magnitude, solar obscuration, altitude and observable phase duration? |
| Chart | What do the Washington angles, houses, ruler, root and aspects say at syzygy? |
| Boundary | What belongs to astronomy, what belongs to astrological interpretation, and what would require an external factual receipt? |

Three restraints follow:

1. **Global totality is not local totality.** Never use the global label as a
   Washington visibility claim.
2. **Local invisibility does not void the chart.** The chart is cast for the
   exact syzygy; path visibility is an added place-specific condition.
3. **Visibility is staging, not evidence.** A witnessed eclipse may feel more
   embodied or publicly available, but it receives no extra factual vote and
   does not make an interpretation true.

The useful story-room translation is:

- global path = where the touring production physically opens;
- Washington visibility = whether the national-stage audience can see it;
- horizon condition = entrance, exit or full-stage presence;
- chart angles and houses = the political set and camera placement;
- syzygy = the astrology cue;
