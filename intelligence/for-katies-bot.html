How to go deeper

  1. Open bot-instructions.html, then bot-index.html.
  2. Open api/v1/index.json for the API contract.
  3. Use package-inventory.json when one package name hides many distinct internal objects.
  4. Choose packages in api/v1/packages.json and read each package's full_text_url.
  5. For a public reading, prefer its static reading_url. For access_state: public_machine_data, open data_url and preserve the schema, as-of date and evidence vocabulary.
  6. For access_state: private_by_design, use metadata only.
  7. Use the connected story map only when the question crosses packages.
  8. Freshly verify anything that must be current today.
