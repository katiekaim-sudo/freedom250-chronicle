## Bottom line

The OIG did more than criticize one construction project. Its seventh
recommendation asks the Board to create an agency-wide framework for future
significant initiatives. The report says that the Board should recognize when
it is a **nonexpert owner**—including in construction and planned information-
technology modernization—and should import the expertise, independent challenge,
fixed baselines, cost transparency and escalation machinery appropriate to the
work.

That creates a new institutional-control storyline:

> specialized public authority does not automatically produce specialized
> delivery competence.

The observable transition is from internal self-reliance to a governed model
of outside execution expertise and independent assurance. The current evidence
establishes the diagnosis, seven recommendations and Chairman Warsh's
concurrence and directions. It does **not** yet establish a signed project
ceiling, an engaged auditor, validated awards, a recovery, an issued agency-wide
policy, use of that policy on IT modernization, or durable OIG closure.

## What this package watches

The watch follows one evidence chain:

> diagnosis → accountable owner → imported expertise → fixed baselines →
> open-book cost record → independent validation → remedy → agency-wide policy
> → first reuse → measured result → durable closure

It keeps separate the clocks for direction, appointment, engagement,
data custody, audit work, finding, remedy, capitalization, policy issuance,
reuse and OIG closure. A later state never backfills an earlier one.

## Boundaries

- This is not an audit of monetary policy and does not imply that the Federal
  Reserve is generally nonexpert.
- It is not a conclusion that the renovation's final cost is reasonable or
  unreasonable.
- Chairman concurrence is not implementation; an audit engagement is not an
  audit result; questioned cost is not recovered cash or credit.
- Closing a recommendation is not enough if the same weakness recurs on the
  next major initiative.
- Planned IT modernization is a future application identified by the OIG, not
  a finding that the IT program has failed.
- Aggregate construction in process is not the Eccles-1951 subsidiary ledger.
- This package is factual Workbench research. It makes no astrology claim and
  does not change the Chronicle, a canonical watch or the installed app.
