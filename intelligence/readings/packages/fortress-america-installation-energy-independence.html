# FORTRESS America and Military Installation Energy Independence

**Status:** `current`
**Evidence cutoff:** 2026-09-30 ET
**Research ID:** `fortress-america-installation-energy-independence`

## Short answer

FORTRESS America is a real department-wide program and governance change. Its September 30 energy objective is independent power for every **major** U.S. military installation so operations can continue when the civilian grid fails. It does not establish that every base is covered, that full installation load must be carried, that installations will disconnect from the grid during normal operations, or that the portfolio is funded, built and tested.

The decisive unresolved issue is the implementation constitution: covered sites, critical-versus-full load, outage duration, fuel assumptions, financing vehicle, ownership/operator, cyber standard, test method and acceptance record.

## Scope

This package follows the installation-energy pillar deeply and maps the other four FORTRESS pillars only far enough to preserve the program boundary. Contested Logistics remains the parent package for fuel, strategic reserves, industrial supply and movement. Military Modernization remains a related owner for force and program modernization. This package does not infer classified vulnerabilities, produce an exhaustive base map, or treat a project announcement as an operating capability.

## Source gap

The official release links the signed memorandum, but the publisher PDF was not retrievable through the available browser, HTTP or PDF-reader paths on September 30. Search indexing exposed the memorandum text and a secondary mirror reproduced it, but this package keeps the memorandum in `official_link_access_hold` state. The accessible official release controls the confirmed public announcement; memorandum-only wording must be rechecked against the signed PDF before quotation.
