Where are the national-security tech programs physically built, and which sites are still secret or undecided?

The program registry places 13 sites. 3 are verified program sites (Eaton FITT project location, Menomonee Falls, Wisconsin; GE Vernova FITT project location, Schenectady, New York; Lockheed Martin GPS IIIF production facility, Denver / Littleton, Colorado). 3 are verified company sites where the program's own work is not shown (Argonne Leadership Computing Facility / Building 240, Lemont, Illinois; nLIGHT beam-combined HEL manufacturing expansion, Longmont, Colorado; Lockheed Martin Aculight high-energy-laser operations, Bothell, Washington). 2 are planned or being built (Natcast Advanced Packaging Piloting Facility, ASU Research Park, Tempe, Arizona (planned); Amkor advanced packaging and test facility, Peoria, Arizona). 5 are not publicly disclosed or not yet decided: NNSA Secret/Restricted Data Enterprise Cloud physical hosting environment; Distributed Bioindustrial Production Capability prototype site; QTIME performer and transition-user test locations; Space Data Network satellite, gateway and integration sites; Protected Tactical SATCOM spacecraft integration and checkout sites.

What's still uncertain

  • Natcast packaging site: ASU Research Park, Tempe, Arizona (planned). Planned Tempe co-location under a nonbinding LOI; final site contracting, construction, tool installation and qualified package flows remain separate gates.
  • A verified company site is a place the company works; the registry does not show that the program's own work is done there.
  • The registry's rules: a facility join needs independent evidence; an unknown applicant field is not a negative.
  • Correction checked 2026-09-09: NNSA June 30 notice establishes an enterprise-authorized AWS environment but describes inaugural Genesis workloads prospectively. Original evidence cutoff is retained; this is a bounded wording correction, not a full refresh.
